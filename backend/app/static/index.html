A link shortener on Kubernetes

A public demo of a small service run the way production services are run.

This site is a link shortener: /{code} redirects to a stored URL. It runs on Kubernetes on Oracle Cloud, deployed by GitOps: every change is a pull request, CI builds and scans the image, and Argo CD rolls it out. Prometheus tracks a 7-day service level objective for the redirects and alerts when it burns too fast.
